La implementación utiliza las interfaces estándar de \texttt{scikit-learn}
para el preprocesado, la validación cruzada y el árbol de decisión. La
descripción del problema, los requisitos de evaluación y la estructura de la
entrega siguen el documento de especificación del proyecto proporcionado para
la asignatura. El notebook contiene las referencias operativas a las funciones
y configuraciones empleadas.
